## 📖 About Maccy

Maccy is a free, lightweight, open-source clipboard manager for macOS that lives in the menu bar. It provides a searchable history of everything you copy with minimal resource usage — offering the most essential clipboard history feature with elegant macOS simplicity.

---

## ❌ Problem: Maccy is hard to access

- **macOS Only** — No Windows or Linux version available
- **Basic Feature Set** — Missing advanced features like snippet organization and cloud sync
- **Privacy Considerations** — Clipboard history stores all copied content including passwords
- **Menu Bar Only** — No standalone window view for browsing large clipboard histories
